API de Resttek (1.0.0)

Download OpenAPI specification:

API REST de la plataforma de gestión de restaurantes Resttek.

Autenticación: JWT en la cabecera Authorization: Bearer <token>. El token se obtiene con POST /auth/login o POST /auth/register. Los endpoints públicos y /auth/* no requieren token.

Roles: admin, manager, camarero, cocinero, cliente. Cada operación indica los roles permitidos.

Formato de errores: los errores de dominio responden { "error": "<NombreDelError>", "message": "<detalle>" }. Los middlewares de autenticación/autorización y el módulo de pedidos responden solo { "error": "<mensaje>" }.
